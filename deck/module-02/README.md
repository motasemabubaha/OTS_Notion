# PEHT Module 02 — Building the Practice Lab

Slide deck generator for Professional Ethical Hacking Track, Module 02.
Output: `PEHT_Module02_Building_the_Practice_Lab.pdf` (54 slides, 16:9 1920×1080).

## Build
```
npm i pptxgenjs react-icons react react-dom sharp
# install Barlow + JetBrains Mono fonts locally, then:
node deck.js            # -> PEHT_Module02_Building_the_Practice_Lab.pptx
./build.sh              # pptx -> pdf via LibreOffice
```

Entry point `deck.js` wires the module-level slides (`s_module.js`) and the
four lessons (`s_l1`–`s_l4`). Shared drawing primitives live in `lib.js`.
Cover artwork and the brand logo chip are generated by `art.py`.
